# Auditguard
AuditGuard is an automated IT compliance auditing platform built with Django, React, and Electron. It audits system configurations against security policies, generates detailed PDF reports, and supports multi-endpoint deployments with real-time task processing via Celery and Redis.


🛡️ AuditGuard — A cross-platform IT audit and compliance management system that automates security checks, policy enforcement, and report generation across Windows and Linux environments.
